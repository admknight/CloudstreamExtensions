# Adam Knight Mega Repo v1.0.0

The first stable release of **Adam Knight Mega Repo** — an automatically maintained CloudStream extensions and plugins repository.

v1.0.0 establishes the production foundation: automated upstream aggregation, package verification, duplicate/version resolution, custom-provider builds, health monitoring, publication safety, and a public project site.

## Production state at release

- **540** package-reachable CloudStream plugins
- **35** active upstream, recovery, and custom sources
- **0** package failures
- Daily automatic repository refresh
- Automatic duplicate and version selection
- Last-known-good publication safety gates
- Automatic GitHub publication retries
- Dedicated `custom-builds` branch
- **6** locally maintained custom providers
- Scheduled custom-provider website health monitoring
- Search-friendly GitHub Pages project site

## Custom providers included

- CinevezProvider v1
- Cinemaluxe v36
- World4uFree v14
- Full4Movies v17
- Cinedoze v1
- India4Movies v1

## Install

In CloudStream:

**Settings → Extensions → Add Repository**

Enter:

```
admknight
```

Or use the repository manifest:

```
https://raw.githubusercontent.com/admknight/CloudstreamExtensions/refs/heads/master/repo.json
```

Package availability confirms that an extension package can be fetched. It does not guarantee that every third-party provider website or runtime feature is always operational.
