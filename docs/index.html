WHY THIS REPO

Built for resilience

Automatic daily updatesConfigured upstream repositories are refreshed without manual catalog maintenance.
Duplicate resolutionThe preferred reachable plugin is selected using version and source-priority rules.
Package verificationPublished packages are checked before they enter the live production catalog.
Safety gatesSuspicious catalog drops and upstream failures cannot silently replace known-good production.
Custom build pipelineLocal provider modules are discovered, compiled, published and merged automatically.
Health monitoringCustom provider websites are checked separately without destructive auto-removal.
