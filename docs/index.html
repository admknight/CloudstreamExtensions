Browse in Extension Explorer

Search by name, language or type and bookmark names on this device. The Explorer does not install plugins or build repository links.

Result: local bookmarks only — nothing added to CloudStream
Open Extension Explorer →

These are different tools, not three install buttons. Full and personal repositories make plugins available in CloudStream; adding either repository does not install plugins. Explorer bookmarks remain in your browser and do not automatically appear in the Builder.

OFFICIAL COMPANION · SEPARATE SERVICE

Personal Bundles

Build a smaller repository without changing the full MegaRepo.

Your plugins, one personal repository link.

Choose up to 100 published extensions and generate a selected-only repo.json link. The separate Cloudflare Worker uses MegaRepo's current published metadata for those plugin identities: no account, no repackaged plugin binaries, and no changes to the full catalog.

Each link represents a fixed selection. Make a new link to change that selection; then add the repository in CloudStream and install individual plugins yourself.

WHY THIS REPO

Built for resilience

Guarded refreshes every three hoursConfigured upstream sources are reconciled frequently to reduce stale plugin metadata.
Duplicate resolutionThe preferred reachable plugin is selected using version and source-priority rules.
Package checks and integrity auditingPublication checks URL reachability; a separate hourly read-only audit compares upstream metadata and rotates package checksum verification.
Safety gatesSuspicious catalog drops and upstream failures cannot silently replace known-good production.
Custom build pipelineLocal provider modules are discovered, compiled, published and merged automatically.
Health monitoringCustom provider websites are checked separately without destructive auto-removal.
