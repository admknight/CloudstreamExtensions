CloudStream Plugins & Extensions Repository

Adam Knight Mega Repo combines published CloudStream extensions into one maintained, installer-friendly repository with automated updates, duplicate resolution, package checking and custom-provider monitoring.

View on GitHub Repository manifest Browse production catalog

Install the Mega Repo in CloudStream

In CloudStream, open Settings → Extensions → Add Repository and use the shortcode:

admknight

You can also use the raw repository manifest:

https://raw.githubusercontent.com/admknight/CloudstreamExtensions/refs/heads/master/repo.json

What this CloudStream repository provides

Hundreds of extensions
Movies, TV, anime, live TV, sports, tools, games and multilingual providers from many published repositories.
Automatic daily updates
The production catalog is rebuilt on schedule and when repository configuration changes.
Package verification
Published .cs3 packages are checked before they are included in the live catalog.
Duplicate resolution
When the same plugin appears in several sources, version and source-priority rules select the preferred reachable package.
Custom providers
Locally maintained CloudStream providers are built on a dedicated branch and automatically merged into the main catalog.
Safety gates
Unexpected catalog drops or upstream failures are blocked from replacing the last known-good production catalog.

Repository branches

master contains source configuration, custom provider source code and automation. builds contains the production CloudStream catalog. custom-builds contains compiled custom providers.

Automated health monitoring is enabled for custom provider websites.

For CloudStream users and maintainers

This project is useful if you are searching for a maintained CloudStream plugin repository, a CloudStream extensions list, a single repo URL for multiple providers, or an automatically refreshed index that preserves source provenance and avoids dead package entries.

See the main GitHub README for the current plugin dashboard, category counts, source health, package health, build history and provenance information.

Maintained by Adam Knight. This project is an extension index/build project and does not host video or media content. Package availability does not guarantee that every third-party provider website is operational at runtime.
