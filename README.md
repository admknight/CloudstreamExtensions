## 🌐 Installation

To add this Mega-Repo to your Cloudstream app:

1. Open **Cloudstream** and navigate to **Settings** (⚙️) -> **Extensions**.
2. Tap on **Add Repository**.
3. Enter the following URL:
   ```text
   https://raw.githubusercontent.com/admknight/CloudstreamExtensions/builds/plugins.json
   ```
4. Tap **Add Repository** and enjoy the massive collection!

## 🔄 Automation Engine

This repository is powered by a custom **Auto-Sync Engine** that pulls the latest code from **7 different community sources** every 24 hours.

*   **Branded Content**: Every plugin is automatically re-authored to **Adam Knight**.
*   **Self-Hosted Icons**: Icons are mirrored locally to prevent broken images in the app.
*   **Version Control**: The engine automatically selects the highest version available among all sources.
*   **CI Validation**: Only plugins that successfully compile reach the final build.
